# Student Planner
Планировщик учебных задач - учебный проект для огрнизации заданий и дедлайнов

## Возможности
- добавление учебных задач
- отметка выполненных задач
- сортировка по дедлайну

## Текущая версия 
1.0

## Целевая аудитория
Планировщик предназначен для студентов, которые хотят системаизировать учебные задачи 

## Принципы использования
1. добавляйте задачи сразу после получения задания
2. указывайте дедлайны 
3. регулярно отмечайте выполненные пункты
